Hecho para quien editaBuilt for editors

Menos pasos entre el enlace y tu línea de tiempo.Fewer steps between the link and your timeline.

✂

Cortes exactos al cuadroFrame-accurate cuts

Marcás inicio y fin y obtenés solo ese tramo, con cada fragmento en su propio archivo y con el nombre que elijas.Set a start and an end and get only that part, each clip in its own file with the name you choose.

▣

Formatos para editarEditing-ready formats

MP4, MOV, ProRes, WebM, MKV o solo audio, con perfiles listos para Premiere y los tuyos guardados.MP4, MOV, ProRes, WebM, MKV or audio only, with Premiere-ready profiles and your own saved ones.

⏱

Velocidad constanteConstant frame rate

Convierte material de cuadros variables (celular, grabaciones de pantalla) para evitar desfases de audio al editar.Converts variable-frame-rate footage (phones, screen recordings) to avoid audio drift while editing.

☰

Cola de trabajoWork queue

Armá una lista, cambiá el formato o el fragmento de cada elemento y abrí su ficha con miniatura y descripción.Build a list, change each item's format or clip, and open its card with thumbnail and description.

⌕

Scraping

Cargá un canal o una lista, filtrá por fechas, duración o título, y mandá a la cola solo lo que te sirve.Load a channel or playlist, filter by date, length or title, and send only what you need to the queue.

▭

Modo miniMini mode

Una ventana chica que queda siempre encima, para pegar enlaces y ver el progreso sin salir de tu editor.A small always-on-top window to paste links and watch progress without leaving your editor.

Paso a pasoStep by step

Tres pasos, sin configurar nada al principio.Three steps, nothing to set up at first.

Pegá el enlacePaste the link

Un video, una lista o un archivo de texto con varios enlaces.One video, a playlist, or a text file with several links.

Elegí perfil y fragmentosPick a profile and clips

Un perfil para el formato, y fragmentos si querés solo una parte.A profile for the format, and clips if you only want a part.

Descargá y editáDownload and edit

Los archivos quedan en tu carpeta, listos para arrastrar a tu editor.Files land in your folder, ready to drag into your editor.

Preguntas frecuentesFrequently asked questions

¿Qué necesito para usarlo?What do I need to use it?

Una PC con Windows 10 u 11. No hay instalador: descargás el archivo, lo abrís y listo.A Windows 10 or 11 PC. There is no installer: download the file and open it.

¿Qué hace con mis datos?What does it do with my data?

Todo se procesa en tu computadora. videoprep no tiene cuentas ni recopila datos de uso.Everything is processed on your computer. videoprep has no accounts and collects no usage data.

¿Cómo se actualiza?How does it update?

Avisa cuando hay una versión nueva y la instala con un botón, verificando que el archivo descargado no esté dañado.It tells you when a new version is out and installs it with one button, checking the downloaded file is not corrupted.

¿Qué sitios admite?Which sites does it support?

Los que admite yt-dlp, el proyecto que videoprep usa por dentro. La compatibilidad puede cambiar con el tiempo.Those supported by yt-dlp, the project videoprep uses under the hood. Compatibility can change over time.

¿Hay versión para Mac o Linux?Is there a Mac or Linux version?

Por ahora solo Windows. Está pensado para poder llevarlo a otros sistemas más adelante.Windows only for now. It is designed so it can be brought to other systems later.

Uso responsable.Responsible use. Usá videoprep solo con contenido que tengas derecho a descargar y de acuerdo con las condiciones de cada sitio. Cada persona es responsable del uso que le da.Use videoprep only with content you have the right to download and in line with each site's terms. Each person is responsible for how they use it.
