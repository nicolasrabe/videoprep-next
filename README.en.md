# videoprep

**[Español](README.md)**

Free tool for video editors: paste a link (YouTube and any site yt-dlp supports), pick format, clips and names, and
download edit-ready files.

> **Status:** version 0.2.0 is in development (C#/.NET rewrite). It does not download anything yet.
> The working version today is 0.1.1 (PowerShell), in the `legacy-ps/` folder.

Uses [yt-dlp](https://github.com/yt-dlp/yt-dlp), [FFmpeg](https://ffmpeg.org) and [Deno](https://deno.com), downloaded
on first run (not included in this repository).
